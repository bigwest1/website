# Design System Tokens

## Visual Direction

Premium navy-led creative suite with restrained gold, cyan, and coral accents used only to signal priority, actionability, or validation state.

## Core Tokens

### Color

- Base canvas: deep navy ink.
- Elevated surfaces: desaturated midnight blue layers.
- Primary action: luminous marine blue.
- Success: green-cyan blend with strong readability.
- Warning: controlled amber.
- Critical: coral-red that reads clearly on dark surfaces.

### Typography

- Display and interface: `Sora`.
- Technical and diagnostics: `JetBrains Mono`.
- Strong size contrast between page identity, module headings, and inspector metadata.

### Spacing

- 4px internal token scale.
- 24px default screen gutter.
- 20px panel padding.
- 12px compact control spacing.

### Radius

- 12px for controls.
- 20px for major surfaces.
- 28px for hero cards and spotlight panels.

### Motion

- Fast hover response below 160ms.
- Workspace transitions around 220ms with ease-out.
- Staggered reveal for lists and cards; no ornamental motion loops.
