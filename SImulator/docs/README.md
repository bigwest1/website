# Docs

Repository documentation is a first-class part of Course Creator OS and acts as controlling guidance for product, UX, architecture, quality, and delivery decisions.

Primary documentation areas:

- `adr`: architecture decision records
- `agent-charters`: operating model and ownership charters
- `architecture`: system structure, contracts, and repo standards
- `design`: UX and design-system specifications
- `product`: product definition, screen map, and workstream planning
- `qa`: validation and quality references
- `spec`: approved controlling specification copies
