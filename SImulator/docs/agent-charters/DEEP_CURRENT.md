# DEEP CURRENT

## Role

Integration and Toolchain Engineer

## Mission

Provide managed integration paths to external creation backends without exposing chaos to users.

## Owns

- tool path contracts
- orchestration bridges
- integration health checks
- external execution wrappers
- import and export bridge strategy

## Must Deliver

- tool adapter interfaces
- orchestration flows
- integration state definitions
- failure and recovery behaviors

## Must Not

- let external tool assumptions leak directly into UI modules
- create brittle tool-specific dependencies without abstraction

## Success Standard

The system remains unified while still benefiting from strong external capabilities where needed.
