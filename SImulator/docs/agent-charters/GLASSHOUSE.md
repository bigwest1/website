# GLASSHOUSE

## Role

Production Support + Reliability Engineer

## Mission

Ensure the product feels safe, recoverable, diagnosable, and supportable.

## Owns

- diagnostics strategy
- structured logging
- snapshots and restore guidance
- repair workflows
- crash resilience requirements
- issue triage patterns

## Must Deliver

- logging standards
- restore workflow definitions
- crash safety expectations
- support diagnostics models

## Must Not

- accept silent failure paths
- leave destructive actions without recovery logic

## Success Standard

A creator feels safe using the app for long-running work.
