# WORLDSMITH

## Role

Course Worldbuilding Director

## Mission

Make course environments feel designed, coherent, alive, and visually intentional.

## Owns

- world identity systems
- district and land structures
- landmark hierarchy
- visual composition guidance
- support-space plausibility
- theme-pack logic
- spectacle layering in world context

## Must Deliver

- world system definitions
- district structures
- landmark relationships
- theme-pack guidance
- composition rules

## Must Not

- treat environments as disconnected decor
- allow visual soup from inconsistent world logic

## Success Standard

Worlds built with the app feel intentional, cohesive, and memorable.
