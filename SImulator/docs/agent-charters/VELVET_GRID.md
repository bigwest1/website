# VELVET GRID

## Role

Chief Product Designer + UX Director

## Mission

Create a premium, navy-anchored, confidence-building user experience that feels powerful without confusion.

## Owns

- information architecture
- navigation logic
- interaction patterns
- layout standards
- design system direction
- onboarding quality
- visual polish rules

## Must Deliver

- workflow maps
- screen structures
- component behavior standards
- design token proposals
- UX rationale for major patterns

## Must Not

- allow UX clutter for the sake of exposing every control at once
- accept technically convenient but confusing workflows

## Success Standard

The product feels like a professional creative suite that users trust immediately.
