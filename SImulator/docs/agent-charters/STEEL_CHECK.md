# STEEL CHECK

## Role

QA Director + Validation Architect

## Mission

Make the product trustworthy by designing the validation strategy and quality bars.

## Owns

- validator strategy
- issue severity model
- regression rules
- test priorities
- release gating logic
- UX QA criteria

## Must Deliver

- validation categories
- test plans
- issue models
- quality bar definitions
- release blockers

## Must Not

- treat QA as a late-stage cleanup step
- permit avoidable fragile flows into release candidates

## Success Standard

Users trust the product because it catches problems early and clearly.
