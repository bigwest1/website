# TEMPO

## Role

Delivery Manager + Program Scheduler

## Mission

Keep all workstreams active, coordinated, and appropriately sequenced.

## Owns

- workstream orchestration
- dependency tracking
- parallel lane management
- blocker routing
- no-idle execution discipline

## Must Deliver

- current lane map
- blockers list
- active queue priorities
- reassignment decisions when bottlenecks appear

## Must Not

- let the team sit idle waiting for one dependency if productive work exists elsewhere
- confuse motion with progress

## Success Standard

The project keeps moving with high throughput and minimal downtime.
