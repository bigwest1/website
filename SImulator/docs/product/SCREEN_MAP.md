# Screen Map

## Global Layout

- Left navigation rail for module switching.
- Central workspace for task execution.
- Right rail for inspector, validation, agent guidance, and next actions.
- Persistent project-health status in the shell header.

## Screens

### Home

- Purpose: orient the creator and surface project health.
- Primary blocks: recent projects, diagnostics pulse, quick actions, package/release history.

### Create

- Purpose: create a project with sane defaults and clear target profiles.
- Primary blocks: intent capture, output posture, target hardware, validation profile, starter outputs.

### Plan

- Purpose: define the course bible and the hole-by-hole plan in one planning mode.
- Primary blocks: course identity, style grammar, technical constraints, hole planner board.

### Build

- Purpose: connect landform decisions to routing and playability.
- Primary blocks: terrain stages, routing overlays, elevation notes, hazard intents.

### Gameplay

- Purpose: own gameplay metadata and export-critical simulator logic.
- Primary blocks: tee and pin sets, hazards, surfaces, drop zones, minimap and flyover inputs, readiness checks.

### Asset Library

- Purpose: ingest, classify, normalize, and track assets.
- Primary blocks: asset groups, metadata inspector, usage map, status labels.

### World

- Purpose: turn course canon into a cohesive world.
- Primary blocks: district map, spectacle moments, environmental systems, continuity checks.

### Animate

- Purpose: define event states, timing, and reactive world systems.
- Primary blocks: event graph, triggers, scene timing, validation notes.

### Playability Center

- Purpose: find gameplay and readability problems early.
- Primary blocks: shot lines, risk zones, blind spots, recovery options, issue list.

### Performance

- Purpose: manage playback targets and optimization effort.
- Primary blocks: target profile, budget meters, hotspots, optimization tasks.

### Preview

- Purpose: preview the course as a product, not only as data.
- Primary blocks: flyover plan, minimap plan, showcase shots, review queue.

### Package

- Purpose: produce and validate release candidates.
- Primary blocks: export profile, blockers, package contents, diagnostics, output history.

### Publish

- Purpose: prepare release metadata and public-safe posture.
- Primary blocks: release notes, credits, media checklist, publish-safe validation.

### Version Control Center

- Purpose: preserve safe iteration and recovery.
- Primary blocks: snapshots, milestone notes, branch/status signals, restore options.

### Agent Command Center

- Purpose: coordinate guided execution and assistant-driven work.
- Primary blocks: active priorities, delegated tasks, agent lineup, decision log references.

### Settings

- Purpose: manage defaults, tool paths, integrations, and diagnostic behavior.
- Primary blocks: project defaults, output preferences, validation strictness, managed integrations.
