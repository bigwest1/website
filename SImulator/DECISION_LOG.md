# Decision Log

## Purpose

This log records durable product, architecture, UX, delivery, and governance decisions that should not be rediscovered through chat history. If a decision materially changes package boundaries, workflow structure, compatibility posture, or delivery language, it belongs here.

## Usage Rules

- Record decisions once they affect implementation direction beyond a single file.
- Do not reopen accepted decisions without new evidence, a clear downside, or a stronger replacement.
- Update implications when the decision evolves in scope but not in intent.
- Reference the owning domain when a future reader needs to know who should revisit the decision.
