# Module Status Board

## State Legend

- `Not Started`: no durable structure yet
- `Defined`: owned and specified, but not meaningfully built
- `In Design`: interaction or contract work is active
- `In Build`: implementation is underway on real product surfaces
- `In Validation`: contracts exist and correctness/readiness hardening is active
- `Ready for Integration`: module is stable enough to connect into broader flows
- `Ready`: module meets current quality and readiness expectations
- `Blocked`: forward progress depends on unresolved upstream work
