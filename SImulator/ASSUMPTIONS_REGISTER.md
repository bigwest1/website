# Assumptions Register

## Product Guardrails

- Course Creator OS must feel premium, modern, calm, and trustworthy.
- Navy blue remains the primary visual anchor.
- UX is equal in importance to technical capability.
- Creators must never feel lost or blocked without an action path.
- The platform must support many course styles, not only theme parks.
- The first flagship course remains a modern premium theme park course.
- Simulator logic that matters to creators must be configurable in-app.
- Managed integrations must remain behind a unified product experience.
- Output must preserve a reliable GSPro-ready path.
- The target playback machine remains `i7-8086K / RTX 4080 Super / 64 GB / NVMe`.

## Operating Assumptions

- Reversible decisions should be made quickly without waiting for routine approval.
- Domain ownership should stay explicit rather than shared ambiguously.
- The project should prefer long-term architecture quality over shallow velocity.
- SQLite is an indexed local state layer, not the only source of truth.
- Project files must remain recoverable even if the local index is rebuilt.

## Open Assumptions To Revisit

- The eventual integration set for external course-authoring backends is still intentionally abstracted behind adapter interfaces.
- The current desktop shell remains the primary execution surface until a future multi-user or cloud requirement is explicitly introduced.
- The Agent Command Center will remain guidance-first rather than autonomous-background-first unless user intent changes.
